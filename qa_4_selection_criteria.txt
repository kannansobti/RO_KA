
JJM TO SHRUG MAPPING - SELECTION CRITERIA DOCUMENT
===================================================

BACKGROUND:
-----------
The mapping chain is: JJM Village -> LGD Village -> LGD GP -> SHRUG

The many-to-many relationship arises because multiple SHRUG (Census) villages 
can belong to one Gram Panchayat (GP). When joining through the GP code, 
each JJM village gets matched to ALL SHRUG villages in its GP.

SELECTION METHOD:
-----------------
For the final 1:1 mapping, we selected ONE SHRUG village per JJM village using:

PRIORITY 1 - EXACT VILLAGE MATCH:
  - Condition: JJM's LGD Village ID equals SHRUG's SHRID ID
  - This indicates the same village exists in both JJM and Census/SHRUG
  - Most reliable match type
  - Result: 25553 exact matches (95.8%)

PRIORITY 2 - GP-LEVEL MATCH:
  - Condition: No exact match available
  - Selection: First SHRUG village in the same GP
  - The JJM village shares a GP with the SHRUG village
  - Less precise - use with caution for village-level analysis
  - Result: 1125 GP-level matches (4.2%)

NO MATCH:
  - JJM villages without any SHRUG linkage
  - Result: 338 villages (1.3%)

FILES GENERATED:
----------------
1. jjm_to_shrug_mapping_final.csv - Clean 1:1 mapping (recommended)
   - Column 'exact_village_match': True = exact match, False = GP-level match
   
2. jjm_to_shrug_complete_mapping.csv - Full many-to-many mapping
   - Use this to see all SHRUG villages linked to each JJM village
   
3. qa_4a_jjm_to_multiple_shrug.csv - JJM villages with multiple SHRUG matches
4. qa_4b_shrug_to_multiple_jjm.csv - SHRUG villages with multiple JJM matches

RECOMMENDATION:
---------------
- For village-level analysis: Use only records where exact_village_match = True
- For GP-level analysis: All records can be used
- For exploring alternatives: Use the complete mapping file
